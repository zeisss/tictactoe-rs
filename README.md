# TicTacToe in Rust

Simple playground project to have done something with Rust and play around with various UI technology stacks and maybe some networking. Implements the game logic for [Tic-Tac-Toe](https://en.wikipedia.org/wiki/Tic-tac-toe).

* `tictactoe_ratatui` - Local TicTacToe with [Ratatui](https://ratatui.rs/)
* `tictactoe_sdl3` - Reuses tictactoe game module but with [SDL3](https://docs.rs/sdl3/latest/sdl3/) for the UI
* `tictactoe_raylib` - Reuses tictactoe game module but with [Raylib](https://docs.rs/raylib/latest/raylib/) for the UI
